# AurigaX Homebrew tap

## Ostia

[Ostia](https://github.com/aurigax-ai/ostia) for macOS on Apple silicon.

```sh
brew install --cask aurigax-ai/tap/ostia
```

Upgrade:

```sh
brew upgrade --cask ostia
```

Uninstall (add `--zap` to also remove settings and data):

```sh
brew uninstall --cask ostia
```

`Casks/ostia.rb` is updated by the Ostia release workflow for every release.
